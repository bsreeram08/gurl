CLI reference

CLI reference

One page per command, in alphabetical order. Every page has the same layout: synopsis, flags, aliases, examples and related commands. Flag tables are checked against gurl docs --json from the binary; run gurl docs for the reference that matches your installed version.

Commands

CommandWhat it does
authList auth handlers and their parameters
codegenGenerate Go, Python, JavaScript or curl code from a request
collectionManage collections, their variables, and collection runs
cookiesList, delete and clear stored cookies
deleteRemove a saved request
detectParse a curl command from stdin or a file
diagInspect one recorded execution
diffCompare the latest responses of a request
docsPrint a compact reference of every command and concept
editChange fields of a saved request
envManage environments and their variables
execRun a command with an environment’s variables injected
exportExport requests to a file
extractTest extraction rules against a sample response
graphqlExecute a GraphQL query
grpcExecute a gRPC request
historyShow execution history for a request
importImport from OpenAPI, Insomnia, Bruno, Postman, HAR or gurl exports
initInitialize a project (.gurl/)
listList saved requests
pasteCopy a request as curl to the clipboard
renameRename a saved request
runExecute a saved request
saveSave a request under a name
sequenceSet execution order within a collection
shellLaunch the typed interactive shell
showShow a saved request
sseConnect to a Server-Sent Events endpoint
timelineShow executions across all requests
updateUpdate gurl to the latest release
wsOpen a WebSocket connection

gurl tui is a hidden, non-functional stub; use gurl shell for interactive use.

Global flags

These work with every command, in any position.

FlagShortDescription
--agentJSON output, no prompts, strict masking (or GURL_AGENT=1, or run the binary as agentgurl). See Agent mode.
--no-inputNever prompt; fail and name what to pass instead (or GURL_NO_INPUT=1)
--project-dirProject root containing .gurl file storage (or GURL_PROJECT_DIR)
--version-vPrint the version

Exit codes

0 success, 1 error, 2 usage error; gurl exec exits with its command’s code. Details and the JSON error shape are in JSON output.
